# Reinh Edit Kit - инструкции для агента

Это набор для монтажа видео с ИИ: скиллы в `skills/`, скрипты в `scripts/`, стандарт в `docs/`, стартовый проект Remotion в `src/`.

## Перед любой работой
1. Прочитать `YOUR_RULES.md` (правила владельца проекта - главнее всего остального) и `kit.config.json` (язык, микрофоны, цвета, форматы).
2. Широкая задача («смонтируй», «вот дубли») - начать со скилла `kit-studio`: он выберет цепочку. Скиллы лежат в `skills/kit-*/SKILL.md` (для Claude Code и Codex они подключены через `.claude/skills` и `.agents/skills`).
3. Стандарт монтажа - `docs/EDIT_STANDARD.md`; форматы - `docs/DELIVERY_PROFILES.md`; чего система не умеет - `docs/LIMITS.md`.

## Жёсткие правила
- **Исходники только читать.** Промежуточное - в `work/`, готовое - в `exports/`, финал не перезаписывать (новая версия `_v2`). В FFmpeg исходник передаётся одним явным путём в кавычках сразу после `-i`; никогда не использовать шаблон `*` для исходников и никогда не ставить `-y` в команду, где путь исходника может оказаться на месте выхода.
- **Сначала черновик, потом замечания человека, потом финал.** Не объявлять ролик готовым без просмотра человеком.
- **Локально.** Расшифровка - whisper.cpp на этом компьютере. Ничего не загружать во внешние сервисы и ничего не публиковать без явного разрешения человека.
- **Лицензии.** Музыка, логотипы, шрифты и чужие кадры - только с правом на использование; в репозиторий их не добавлять.
- Измерять, а не угадывать: паузы - по энергии звука, громкость - `voice_master.py measure`, монтаж - `edl_timeline.py --report` и `editorial_qc.py`.
- Отчитываться честно: что проверено, что нет, что требует уха или глаза человека.

## Команды
```bash
bash scripts/doctor.sh                      # что установлено
npm test                                    # все тесты набора
npm run sfx && npm run sample               # звуки и пример исходников
npm run render:example                      # черновики примера в out/
npx remotion studio                         # предпросмотр
python3 scripts/audio/voice_master.py presets
```
