# Черновой монтаж: дубли и паузы

Тишина не равна плохому дублю: дубль выбирается по тексту, а не только по громкости. Резка по тишине (auto-editor) убирает паузы, но не выбирает лучший дубль.

## Шаги
1. **Приём.** `ffprobe` каждого файла: разрешение, fps, длительность, дорожки. Разный fps в одном проекте - предупредить. Исходники не трогать (правило 4 в `kit-studio`).
2. **Синхронизация** (если звук и картинка писались разными устройствами): `node scripts/audio/find_offset.mjs <клип> <длинная запись>` - смещение по огибающей речи; клип, склеенный из нескольких дублей, - `node scripts/audio/sync_pieces.mjs <клип> <запись> out.wav <смещения…>`. Хлопок в кадре в начале записи упрощает синхронизацию.
3. **Расшифровка** локально: `ffmpeg -i <файл> -vn -ac 1 -ar 16000 a16.wav`, затем `whisper-cli -m models/ggml-small.bin -l ru -f a16.wav -ojf -ml 1 -sow -of work/<ролик>/transcripts/<файл>` (язык и модель - из `kit.config.json`).
4. **Сопоставление со сценарием** (если он есть): каждую фразу найти во всех дублях нечётким сравнением слов. Таблица: фраза · дубль · начало/конец · совпадение %.
5. **Выбор дубля** (по убыванию веса): полнота текста → нет мата, оговорок, повторов и хвостов соседнего дубля (расшифровать сам кусок **без `--prompt`**: подсказка заставляет Whisper «чистить» оговорки) → нет посторонних звуков (стук, упавший предмет) → темп и энергия → последний удачный дубль при равенстве. Взгляд в сторону - не повод выкинуть удачный по речи дубль: отметьте секунды, их закроет вставка.
6. **Паузы** (стандарт `docs/EDIT_STANDARD.md` §1): резать только в тишине, **измеренной по энергии** (окна 10-20 мс), - таймкоды слов Whisper на паузах растянуты на секунды. Начало клипа - по началу речи из энергии; конец - не раньше 0.2 с после последнего всплеска (Whisper ставит конец слова раньше). Воздух 0.08-0.12 с до слова, 0.10-0.15 с после; между предложениями итог 0.25-0.4 с. Повтор той же фразы на стыке кусков - срезать.
7. **Джамп-кат на лице** - всегда смена крупности 1.00 ↔ 1.14 (делает `edl_timeline.py`) или перебивка экраном/вставкой. Медленный наезд 1.00 → 1.08-1.12 на куске 4-12 с - `push` в EDL, один-два на главу.
8. **EDL** - данные с причинами: `clips [[in, out, причина]]`, виды `views`, камера экрана `cams`, вставки `gaps`/`overs` по словам. Пример - `examples/edl/`. Проверка: `python3 scripts/edit/edl_timeline.py <edl> --out work/<ролик>/timeline.json --report work/<ролик>/editorial.md` - 0 флагов или каждый флаг с решением «намеренно».
9. **Каждый клип:** `python3 scripts/qc/clip_check.py work/<ролик>/timeline.json` - отдельная расшифровка и края по энергии (громко за краем = слово обрезано).
10. **Короткий вертикальный ролик из готовых кусков:** `python3 scripts/edit/short_cut.py projects/<ролик>/edl.json work/<ролик>/cut` - голос встык, таймлайн и слова для субтитров.
11. Нужен ручной монтаж в редакторе (Premiere, Resolve, Final Cut, Kdenlive) - официальный скилл `auto-editor-export`.

## Выход
`edl.json`, `timeline.json`, отчёт `editorial.md`, таблица выбора дублей с причинами, черновое превью.
