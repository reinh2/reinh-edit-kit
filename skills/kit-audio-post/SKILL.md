# Звук: голос, музыка, SFX, мастер

Цель - естественный тембр, разборчивая речь, ровная динамика. Не максимум шумодава и не максимум громкости. Числа не заменяют слух: итог всегда слушает человек.

## 0. Новый микрофон или новая комната - калибровка (`docs/MIC_CALIBRATION.md`)
1. Человек записывает 30-60 с обычной речи **с 2-3 с тишины в начале** (снимок шума), тем же способом, что и ролик.
2. `python3 scripts/audio/voice_master.py analyze <запись> --name <мой-микрофон>` - уровень, шум, тембр против «среднего голоса» и предложенный пресет.
3. Есть эталон, который нравится (другой микрофон, свой старый ролик)? `python3 scripts/audio/voice_master.py match <запись> <эталон> --name <мой-микрофон>` - подгонка тембра FIR-эквалайзером. Лучше всего - одни и те же слова, записанные обоими микрофонами одновременно.
4. Пресет - в `kit.config.json` → «voicePresets»; затем 2-3 варианта на одном куске, человек выбирает на слух. Выбранный - в «mics».«main».

## 1. Голос
```bash
python3 scripts/audio/voice_master.py presets
python3 scripts/audio/voice_master.py voice <вход> work/<ролик>/stems/voice.wav --preset <пресет> [--channel 0] [--noise 0.5-2.5]
python3 scripts/audio/voice_master.py measure <файл>
```
| Пресет | Для чего |
|---|---|
| `usb-condenser` | любой USB/XLR конденсатор на столе |
| `dynamic` | динамический близко ко рту |
| `lav-generic` | петличка на груди (EQ груди, две ступени компрессии, динамический де-эссер, шумодав по снимку тишины) |
| `headset` | гарнитура, игровые наушники |
| `camera` | встроенный микрофон телефона, камеры, ноутбука |
| `neutral` | без EQ: только срез низа и мягкая компрессия |
| `solocast`, `lav` | проверены на слух на конкретных микрофонах (HyperX SoloCast, DJI Mic Mini 2), для других - стартовая точка |

Правила, выученные на настоящих роликах:
- Компрессор работает на исходном уровне записи; громкость - линейным усилением после цепочки + лимитер с 4× передискретизацией. Не динамический `loudnorm`: он сжимает речь ещё раз (LRA 4.7 → 2.4).
- Шумодав по умолчанию выключен; если нужен - по снимку тишины этой же записи (в пресетах с `denoise`), а не следящий `--denoise`: тот делает голос глухим. Шумодав в самом микрофоне и в обработке не совмещать.
- Один голос на ролик: все куски и вставки с речью - через один микрофон и один пресет.
- Разный тембр двух дублей одного микрофона - выравнивать мягко (≤ 2.5 дБ по полосам), грубая полка звучит неестественно.
- Настольный микрофон слышит стол: всплески низов на нём = стук. Вне слов - подрезать; внутри слова - другой дубль.
- Каждая склейка - 2 кадра фейда (щелчки), края - в тишине по энергии; край проверять на **обработанном** голосе (после компрессора хвост слова громче).

## 2. Музыка
Только с лицензией (`docs/MUSIC_AND_SFX.md`). Длинный ролик - одна спокойная подложка на весь ролик: `python3 scripts/audio/mix_bed.py <ролик.mp4> <трек> work/<ролик>/mixed.mkv --pause-db 11` - петля по тактам, тихое вступление трека один раз, сайдчейн от голоса. **Уровень проверять замером** «микс минус ролик без музыки» на речи (≈ 14-20 дБ ниже голоса) и в паузах. Вертикальный ролик - под речью ≈ 25 дБ ниже голоса.

## 3. SFX
`npm run sfx` синтезирует три пакета в `public/sfx/` (свои звуки, свободны как код). В Remotion - `<Sfx at={…} ev="pop" />` (`src/kit/sfx.tsx`): звук на 2 кадра раньше пика анимации, не чаще одного в 0.6 с, один файл не дважды подряд.

## 4. Мастер
`python3 scripts/audio/voice_master.py master <ролик> exports/<ролик>/<имя>.mp4 --video` → -15 LUFS ±1, true peak ≤ -1.5 dBTP, LRA 4-7, AAC-LC 320k 48 кГц, `+faststart`.

## QC
Голос разборчив на телефонном динамике, нет клиппинга и щелчков, музыка не спорит с голосом, SFX не громче голоса; `measure` финала в отчёт.
