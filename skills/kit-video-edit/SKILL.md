# Монтаж под ключ

Оркестратор: проходит этапы, вызывая профильные скиллы. Перед работой - `YOUR_RULES.md` и `kit.config.json`.

## 0. Приём
- Исходники - в `footage/<дата>/` (только чтение), рабочая папка - `work/<ролик>/`, обработанные куски для Remotion - `public/<ролик>/media/`.
- `ffprobe` каждого файла: разрешение, fps, длительность, дорожки, цветовой профиль. Разный fps (камера 30, экран 60) - нормально, но записать; HDR/HLG с телефона - предупредить: честный перевод в SDR нужен в цветокоррекции, иначе лицо плоское.
- Какое железо у человека - из `kit.config.json` («mics», «formats») и `YOUR_RULES.md`; не угадывать. Новый микрофон - сначала `kit-audio-post`, калибровка.

## 1. Черновой монтаж → `kit-rough-cut`
Лучшие дубли, паузы в измеренной тишине, EDL, `edl_timeline.py --report` без флагов.

## 2. Пруф стиля
Первые 15-30 с со вставками (в вертикальном - с субтитрами) показать человеку до полной сборки, если он не просил «делай целиком».

## 3. Вставки
- **Вставка - анимация по смыслу фразы, а не надпись.** Внутри минимум текста: имя, цифра, одна подпись. Фразу на весь экран и слова у лица не делаем.
- Вставки привязаны к словам (`T(words, "слово")` в `src/kit/words.ts`), не к секундам: перерезка не ломает графику.
- Короткий вертикальный ролик: человек почти всё время в кадре, графика - карточки поверх кадра в свободном месте (`OverlayCard`, `Pill`, `Bar` в `src/kit/Card.tsx`), по одной за раз, 1.5-5 с; плюс 2-3 полноэкранных момента по 3-4 с.
- Длинный ролик: запись экрана - через виртуальную камеру `ScreenCam` (`src/kit/ScreenCam.tsx`): общий план с плиткой лица, крупный фрагмент по событию на экране, размытие почт и ключей. Сырой экран дольше 6 с - дефект.
- Где взгляд ушёл в сторону или дубль снят с другим кадром - закрыть полноэкранной вставкой, а не менять удачный по речи дубль.
- Чужие логотипы, музыка и кадры - только с правом на использование (`docs/MUSIC_AND_SFX.md`).
- **Стили анимации** (`docs/ANIMATION_STYLES.md`): `light` и `cine`, по умолчанию - `kit.config.json` «style». Большие моменты (хук, главы, результат, финал) - `cine`, объяснения - `light`, на смене стиля или главы - один засвет `LightLeak`. Свои компоненты берут цвета из `useTheme()`, чтобы работать в обоих стилях. Человек меняет стиль словами («акцент зелёный», «главы в кино») - правьте тему или конфиг, а не каждую вставку отдельно; решения - в `YOUR_RULES.md`.
- **3D-герои** (`docs/ANIMATION_STYLES.md`, «3D-герои из Blender»): 1-3 на длинный ролик, где мысль - предмет. Сцена - скрипт `scripts/blender/*.py` по образцу `promo_heroes.py`, сначала кадр `--still`, потом последовательность PNG; в ролике - `Hero3D`; ключевые моменты - на сказанных словах.
- Главы длинного ролика-испытания - `ChapterTimer` с часами-одометром (время из журнала, не выдуманное), постоянный чип `MiniTimer`.
- Для сложной анимации - официальные скиллы `remotion-*` (`npx skills add remotion-dev/skills`).

## 4. Субтитры → `kit-captions`
Вертикальные - в кадре; длинные - не вжигать. Отдельный `.srt` - всегда.

## 5. Звук → `kit-audio-post`
Голос по пресету своего микрофона (`voice_master.py voice --preset …`), музыка и SFX, мастер -15 LUFS.

## 6. Сборка в Remotion
- Компоненты набора - `src/kit/`, пример - `src/example/Example.tsx`. Таймлайн - из `edl_timeline.py` (`timeline.json`): Remotion только рисует готовые таймкоды.
- Форматы - `kit.config.json` «formats» и `docs/DELIVERY_PROFILES.md`.
- **Сначала черновик:** `npx remotion render <id> out/<ролик>_draft.mp4 --scale=0.5` (720p из 1440p) или прокси исходников (`scripts/edit/make_proxies.py`). Человек смотрит и пишет замечания с таймкодами по черновику; исправить **все**, потом один финальный рендер в полном качестве.
- Длинный ролик с тяжёлым `public/`: собрать бандл один раз (`npx remotion bundle`) и рендерить из него, иначе каждый рендер копирует все исходники.
- Стандарт монтажа - `docs/EDIT_STANDARD.md`: резать в измеренной тишине, джамп-кат = смена крупности, лицо ≤ 12 с без смены, экран крупно ≤ 8 с, общим планом ≤ 6 с, L/J-склейки на стыках лицо ↔ экран, растворения - снаружи вставки (иначе «фантомные кадры»).

## 7. QC → `kit-qc`
Технический и редакторский QC, исправить существенное, перерендерить, повторить все проходы.

## 8. Выдача
`exports/<ролик>/`: MP4, `.srt`, код Remotion + EDL, короткий QC-отчёт. Финал не перезаписывать - новая версия `_v2`.

## Правила
- Оригиналы не трогать (правило 4 в `kit-studio`); промежуточное - `work/`.
- Цифры на экране сверять со сценарием и источниками.
- Монтаж воспроизводимый: EDL → скрипты → Remotion. Ручные правки в редакторе - через `auto-editor-export`.
