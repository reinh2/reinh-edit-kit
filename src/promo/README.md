# Промо-ролик Reinh Edit Kit

16:9, 2560×1440, 60 fps, ≈ 70 с. Собран на компонентах набора (`src/kit/`) - заодно живой пример.

## Три варианта одного ролика
| Композиция | Стиль |
|---|---|
| `Promo` | **основной** (выбор автора, 26.11.2026): большие моменты в `cine`, шаги гайда в `light`, засвет на каждой смене сцены |
| `Promo-Light` | всё светлое - пример темы, не для выпуска |
| `Promo-Cine` | всё в стиле кино - пример темы, не для выпуска |

```bash
npm run promo:vo        # черновой синтезированный голос, только для темпа (public/promo, не в Git)
npm run render:promo    # черновик основного варианта 720p в out/ (все три - render:promo:all)
npx remotion render Promo out/promo_1440p60.mp4   # финал после замечаний
```

3D-герои (хлопушка в хуке, микрофон в шаге 2, кейс в финале): `npm run promo:3d` (нужен Blender, ≈ 15 мин), кадры - в `public/promo3d/` (не в Git). Без них сцены остаются плоскими.

Длина сцены = max(минимум, голос + 0.6 с): после записи настоящего голоса положите файлы `public/promo/vo_<сцена>.wav` и их длины в `public/promo/vo.json` - сцены подстроятся сами.
Музыки нет: подложка - `scripts/audio/mix_bed.py`, затем `voice_master.py master --video`.

## Текст закадра (для записи)
| # | Сцена | Стиль в `Promo` | Текст |
|---|---|---|---|
| 1 | Хук | cine | Это система, на которой я монтирую свои ролики. И я отдаю её бесплатно. |
| 2 | Что внутри | cine | Внутри весь конвейер: дубли, паузы, звук, графика и проверка. Скиллы для агента и скрипты. |
| 3 | Шаг 1 - установка | light | Шаг первый. Установка одной командой: она сама скачает всё нужное и проверит, что работает. |
| 4 | Шаг 2 - микрофон | light | Шаг второй. Ваш микрофон: запишите тридцать секунд, и скрипт подберёт настройки под любой микрофон. |
| 5 | Шаг 3 - агент монтирует | light | Шаг третий. Пишете агенту своими словами. Он выбирает дубли по тексту и режет паузы только в тишине. |
| 6 | Шаг 4 - проверка | light | Шаг четвёртый. Проверка: паузы, застывший экран, вспышки, фантомные кадры и громкость. |
| 7 | Стили анимации | cine | Анимации есть в двух стилях: светлом и кино. И любой вариант можно поменять через агента под свой вкус: просто напишите ему словами. |
| 8 | Чего ИИ не умеет | cine | Вкус и финальное ухо остаются за вами. Сначала черновик, потом ваши замечания, потом финал. |
| 9 | Где взять | cine | Ссылка на набор - в телеграм-канале reinhworks. Забирайте. |

Текст правится в `src/promo/script.json`; длинное тире в нём не использовать.
