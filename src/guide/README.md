# Гайд по установке - текст закадра и снимки

Видео-руководство по установке набора: настоящие снимки окон, минимум анимации. Композиция `Guide` (`src/guide/Guide.tsx`), сцены и текст - `src/guide/script.json`, снимки - `src/guide/shots.json`.

## Как собрать
1. Снимки окон → `work/guide/raw/*.png` (см. ниже), затем `npm run guide:shots` - обрезка заголовков, размытие личного → `public/guide/shots/`.
2. Черновой голос для темпа: `npm run guide:vo` (синтез речи). Финальный голос записывает человек: файлы `public/guide/vo_<id>.wav` с теми же именами и длительности в `public/guide/vo.json`.
3. Черновик: `npm run render:guide` → `out/guide_draft_720p.mp4`; финал: `npx remotion render Guide out/guide_1440p.mp4`.

## Как снимать (приватность)
- Только отдельные окна: `screencapture -x -o -l <номер окна>`, никогда весь экран. Помощники: `source scripts/example/guide_capture.sh` (`tnew`, `trun`, `tshot`, `winid`).
- Окно Терминала открывается скриптом с чистой домашней папкой и коротким приглашением (`tnew`): в кадре нет имени пользователя и имени Mac. Заголовок и вкладку окна `guide_shots.py` отрезает.
- Браузер - отдельный Chrome с временным профилем (`--user-data-dir`, `--app=`), без ваших вкладок.
- Каждый снимок смотреть глазами: пути `/Users/…`, почта, IP. Личное - в `blur` в `src/guide/shots.json`.

## Ждут публикации на GitHub
- `clone` - начало установки через `curl … | bash` (строка «Скачиваю набор в ~/reinh-edit-kit»).
- `update` - повторный запуск той же команды («Набор уже скачан … обновляю»).
До публикации на их месте серые заглушки с именем снимка.

## Текст закадра (по сценам)

1. **Что будет · `intro`** - Это подробная установка Reinh Edit Kit. Покажу каждый шаг на настоящем экране: установку одной командой, проверку, настройку под себя и первый монтаж с агентом.
2. **Что нужно · `need`** - Понадобится Mac, Linux или Windows с WSL, около трёх гигабайт места и интернет на время установки. Для монтажа - агент для программирования: Claude Code, Codex или Gemini CLI.
3. **Установка · `terminal`** - Откройте Терминал. На Mac нажмите Command и пробел, наберите «Терминал» и нажмите Enter. Откроется вот такое окно: сюда мы будем вставлять команды.
4. **Установка · `paste`** - Скопируйте команду установки со страницы набора на GitHub, вставьте её в Терминал и нажмите Enter. Больше ничего вводить не нужно.
5. **Установка · `clone`** - Сначала установщик скачивает сам набор в папку reinh-edit-kit в вашей домашней папке.
6. **Установка · `programs`** - Шаг первый из пяти: программы. FFmpeg, whisper.cpp, Node.js и Python. Что уже стоит, установщик не трогает. У меня всё было, поэтому он пишет «всё уже установлено».
7. **Установка · `brew`** - Если на Mac нет Homebrew - это менеджер программ, - установщик спросит, можно ли его поставить. Нажмите y и Enter, потом введите пароль от Mac. Символы при вводе не видны, так и задумано.
8. **Установка · `npm`** - Шаг второй: Remotion. Это движок, в котором собираются графика и сам ролик.
9. **Установка · `model`** - Шаг третий: модель Whisper для расшифровки речи, почти полгигабайта. Потом расшифровка работает прямо на вашем компьютере, без интернета.
10. **Установка · `sample`** - Шаг четвёртый: звуки для анимаций и пример исходников, чтобы было на чём проверить.
11. **Установка · `tests`** - Шаг пятый: установщик подключает скиллы для агентов, ещё раз всё проверяет и запускает тесты. Если в конце написано ALL OK - всё работает.
12. **Установка · `done`** - В конце он пишет, где лежит набор и что делать дальше. Обычно на всё уходит от пяти до пятнадцати минут, в основном это скачивание.
13. **Проверка · `render`** - Теперь проверим. Зайдите в папку набора и запустите сборку примера. Он соберёт два черновика: горизонтальный и вертикальный.
14. **Проверка · `result`** - Готовые ролики лежат в папке out. Откройте - это первый ролик, собранный набором.
15. **Проверка · `studio`** - А команда npm run studio открывает Remotion Studio в браузере. Здесь можно посмотреть любую сцену покадрово.
16. **Под себя · `config`** - Теперь под себя. В файле kit.config.json - язык, цвета, шрифт и ваши контакты для конечной карточки. Меняйте только значения в кавычках.
17. **Под себя · `rules`** - Рядом файл YOUR_RULES.md. Пишите туда своими словами, какой стиль вам нравится, что нельзя и что уже ломалось. Агент читает его первым.
18. **Ваш микрофон · `analyze`** - Чтобы звук был хорошим именно на вашем микрофоне, запишите тридцать секунд речи, а в начале пару секунд помолчите. Команда analyze покажет уровень, шум и подходящий пресет.
19. **Ваш микрофон · `presets`** - Все пресеты показывает команда presets: USB-микрофон, динамический, петличка, гарнитура, телефон. Если ни один не подходит - попросите агента подогнать звук под запись, которая вам нравится.
20. **Агент · `agent`** - Теперь агент. Если у вас ещё нет Claude Code, Codex или Gemini CLI, поставьте его по инструкции с их сайта. Потом зайдите в папку набора и запустите агента прямо в ней.
21. **Агент · `trust`** - При первом запуске Claude Code спросит, доверяете ли вы этой папке. Выберите стрелкой вниз «Yes, I trust this folder» и нажмите Enter.
22. **Агент · `skills`** - Скиллы набора агент видит сам. Ещё два официальных скилла, Remotion и auto-editor, ставятся отдельно от их авторов: команды установщик напечатал, просто скопируйте их.
23. **Первый монтаж · `footage`** - Первый монтаж. Положите дубли и запись экрана в папку footage, а внутри сделайте папку с датой съёмки.
24. **Первый монтаж · `first`** - Потом напишите агенту своими словами: вот дубли в такой-то папке, смонтируй вертикальный ролик. Он сам выберет нужные скиллы набора и сначала сделает черновик, а потом спросит ваши замечания.
25. **Если что-то не так · `doctor`** - Если что-то не работает, запустите doctor. Он ничего не меняет: проверяет всё по списку и пишет, чего не хватает и какой командой это поставить.
26. **Если что-то не так · `update`** - Чтобы обновить набор, запустите ту же команду установки ещё раз. Он скачает новую версию и доставит только то, чего не хватает.
27. **Windows и Linux · `windows`** - На Windows сначала поставьте WSL: откройте PowerShell от администратора, введите wsl install и перезагрузитесь. Потом откройте Ubuntu и вставьте ту же команду. На Linux - сразу в Терминал.
28. **Вопросы · `outro`** - Если что-то не получилось, пишите в Issues на GitHub или в мой Telegram-канал. Удачного монтажа.
