# Музыка и звуки

## Звуки (SFX) - свои, в комплекте
`npm run sfx` синтезирует три пакета в `public/sfx/` (`v1`, `v2` - по умолчанию, `v3` - тихий «продуктовый» для длинных роликов). Генераторы - `scripts/audio/sfx-synth-v*.mjs`: шум, осцилляторы и фильтры, детерминированно, 48 кГц / 24 бит. Звуки созданы кодом набора и распространяются на тех же условиях (MIT) - используйте в любых роликах.

Правила: звук на 2 кадра раньше пика анимации; не чаще одного в 0.6 с; один файл не дважды подряд (компонент `Sfx` чередует варианты); SFX на 6-10 дБ тише голоса; «удар» (`impact`) - не больше двух на ролик.

Ещё бесплатные звуки: [Kenney](https://kenney.nl/assets?q=audio) (CC0), [Freesound](https://freesound.org) (лицензия у каждого звука своя - берите CC0 или CC BY с указанием автора).

## Музыка - только ссылки
Музыку набор **не содержит**: большинство лицензий разрешает использовать трек в своём ролике, но не раздавать сам файл. Скачивайте сами и проверяйте условия у источника (они меняются):
| Источник | Условия (кратко, проверяйте на сайте) |
|---|---|
| [YouTube Audio Library](https://www.youtube.com/audiolibrary) | бесплатно для роликов на YouTube; у части треков нужно указание автора |
| [Mixkit](https://mixkit.co/free-stock-music/) | бесплатная лицензия Mixkit для роликов |
| [Pixabay Music](https://pixabay.com/music/) | лицензия Pixabay; Content ID иногда всё равно срабатывает |
| [Free Music Archive](https://freemusicarchive.org) | у каждого трека своя Creative Commons |
| Epidemic Sound, Artlist, Musicbed | платная подписка; финал публиковать только с действующей лицензией, превью - для черновиков |

Никогда не вырезайте музыку и звуки из чужих роликов.

## Подложка длинного ролика
Одна спокойная подложка на весь ролик звучит дороже, чем смена треков на каждой главе.
```bash
python3 scripts/audio/mix_bed.py ролик.mp4 трек.mp3 work/<ролик>/mixed.mkv --pause-db 11 --json work/<ролик>/bed.json
python3 scripts/audio/voice_master.py master work/<ролик>/mixed.mkv exports/<ролик>/<ролик>.mp4 --video
```
- Скрипт находит такт трека, играет тихое вступление один раз, дальше по кругу только тело трека целыми тактами, с кроссфейдом на сильной доле.
- Под речью подложка уходит вниз сайдчейном (≈ -6 дБ), в паузах и на главах - громче.
- `--no-intro` - если ролик начинается с тизера (иначе первая секунда без музыки).
- **Проверьте уровень замером**, а не только на слух: «микс минус ролик без музыки» на окнах речи (≈ 14-20 дБ ниже голоса) и пауз. Громкость мастера этого не видит.
