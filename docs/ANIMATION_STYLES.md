# Стили анимации

В наборе два стиля одних и тех же элементов, и их можно смешивать в одном ролике:

| Стиль | Как выглядит | Для чего |
|---|---|---|
| `light` | светлая страница, белые карточки, Inter, один акцентный цвет | объяснения, шаги, цифры, вставки поверх лица |
| `cine` | тёмная глубина с верхним светом и зерном, стеклянные панели, огромное хромированное слово на заднем плане (Oswald), столбик ключевых слов | большие моменты: хук, главы, результат, финал |

Правило из настоящего длинного ролика: **большие моменты - в `cine`, объяснения - в `light`, на каждой смене стиля или главы - один засвет** (`LightLeak`). Засвет не ставится на каждую склейку.

## Как выбрать
- Стиль по умолчанию для всего проекта - `kit.config.json` → `"style": "light"` или `"cine"`.
- Для части ролика - обёртка:
  ```tsx
  import { KitTheme } from "../kit/themes";
  <KitTheme name="cine"><MyChapterCard /></KitTheme>
  ```
- Внутри своего компонента берите цвета и фон из темы, а не вписывайте вручную - тогда он работает в обоих стилях:
  ```tsx
  const th = useTheme();
  <th.Bg t={t} />                          // фон стиля
  <th.BackWord text="звук" t={t} />        // заднее слово (только cine)
  <div style={{ ...th.card, color: th.ink }}>…</div>
  ```

## Готовые элементы
| Файл | Что |
|---|---|
| `src/kit/themes.tsx` | `THEMES`, `KitTheme`, `useTheme` |
| `src/kit/cine.tsx` | `CineBg`, `Chrome` (хромированное слово), `Stack` (столбик слов по сказанным словам), `Glass`, `Callout` |
| `src/kit/chapter.tsx` | `LightLeak`, `ChapterTimer` (глава с часами-одометром), `Odometer`, `MiniTimer` |
| `src/kit/Card.tsx` | `OverlayCard`, `Pill`, `Bar` |
| `src/promo/Promo.tsx` | живой пример: один и тот же ролик в трёх вариантах (`Promo` - смешанный, `Promo-Light`, `Promo-Cine`) |

## Менять словами через агента
Стили - обычный код, и агент правит его по вашей просьбе. Примеры запросов:
- «сделай акцент зелёным» → `kit.config.json` → `brand.accent`;
- «главы в стиле кино, остальное светлое» → обёртки `KitTheme` по сценам;
- «засвет мягче / убери засвет на третьей главе»;
- «заднее слово меньше и прозрачнее» → `BackWord` в `themes.tsx`;
- «сделай третий стиль: тёплый, бумажный, шрифт с засечками» → новая запись в `THEMES`.

Правило набора остаётся: первый рендер любой анимации - черновик, вы смотрите и даёте замечания, агент правит. Свои решения записывайте в `YOUR_RULES.md`, чтобы агент не спорил с ними в следующем ролике.

Слова на экране - минимум: имя, цифра, одна подпись. Анимация показывает мысль, а не повторяет фразу текстом.
