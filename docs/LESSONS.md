# Ошибки ИИ на настоящих роликах и правила, которые из них выросли

| Что случилось | Правило | Где в наборе |
|---|---|---|
| В готовый Short пролез мат из неудачного дубля: Whisper с подсказкой «почистил» текст, и проверка его не увидела | расшифровывать финал и **каждый кусок отдельно, без подсказки** | `kit-qc`, `scripts/qc/clip_check.py` |
| За кадром упал телефон - это было слышно в готовом ролике | отдельный проход «каждая деталь»: взгляд и посторонние звуки на обоих микрофонах | `kit-qc` п. 6 |
| Черновик длинного ролика прошёл техпроверку с паузами по 6-9 с, повтором дубля и 94 с неподвижного экрана | монтаж проверяется отдельно от техники | `docs/EDIT_STANDARD.md`, `edl_timeline.py`, `editorial_qc.py` |
| На растворениях мелькали «фантомные кадры» спрятанного под вставкой лица (человек нашёл десять на глаз) | растворять снаружи вставки, не на склейке; автоматический поиск | `EDIT_STANDARD.md` §5, `ghost_frames.py` |
| Агент перезаписал десять исходников записи экрана: шаблон `*` в пути и флаг `-y` в одной команде FFmpeg | исходник - одним явным путём сразу после `-i`; никогда шаблон и `-y` рядом с исходниками | `kit-studio`, правило 4 |
| Срезались последние слоги («получится», «удачи»): Whisper ставит конец слова раньше | конец клипа - не раньше 0.2 с после последнего всплеска энергии | `EDIT_STANDARD.md` §1 |
| Нормализация громкости `loudnorm` сплющила речь (LRA 4.7 → 2.4) | компрессор на исходном уровне, громкость - линейно + лимитер | `voice_master.py` |
| Следящий шумодав сделал голос с петлички глухим | шумодав только по снимку тишины этой же записи, слабый | пресеты с `denoise` |
| Статичный де-эссер на петличке не снимал ничего (0.0 дБ), шипящие оставались | динамический де-эссер по полосе 6.5 кГц, две ступени компрессии | пресет `lav-generic` |
| Музыкальную подложку задавило сайдчейном на 16 дБ - её не было слышно, а проверка громкости этого не видит | уровень подложки проверять замером «микс минус ролик» | `mix_bed.py`, `kit-audio-post` |
| Тихое вступление трека повторялось в петле - «музыка пропадает» каждые 1.5 мин | петля по тактам только из тела трека | `mix_bed.py` |
| Полноэкранная вставка посреди фразы - зритель услышал «пропал микрофон» | вставка идёт поверх голоса | `EDIT_STANDARD.md` §5 |
