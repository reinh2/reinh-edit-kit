# Reinh Edit Kit

Набор для монтажа видео с ИИ-агентом: скиллы для Claude Code, Codex и Gemini, скрипты на FFmpeg и Python, стандарт монтажа, автоматическая проверка и стартовый проект на Remotion. На этом конвейере смонтированы настоящие опубликованные ролики: длинные 1440p60 и Shorts.

Бесплатно, лицензия MIT. **Версия 0.1 - черновик**, macOS в приоритете, поддержка по мере сил.

> Это не «монтаж за 10 минут одной кнопкой». Агент делает механику: расшифровку, выбор дублей по тексту, паузы, склейки, звук, графику и проверку сотен кадров. Вкус, эмоцию дубля и финальное ухо оставляет вам: сначала черновик, потом ваши замечания, потом финал.

## Что умеет
- **Черновой монтаж по тексту:** локальная расшифровка (whisper.cpp), выбор лучшего дубля по сценарию, резка пауз только в измеренной тишине, джамп-каты со сменой крупности, EDL как данные с причинами.
- **Проверка монтажа, а не только техники:** паузы, застывший экран, вспышки, «фантомные кадры» на растворениях, скачки громкости на склейках, длина каждого плана (`edl_timeline.py`, `editorial_qc.py`, `ghost_frames.py`).
- **Звук под ваш микрофон:** пресеты по типам (USB-конденсатор, динамический, петличка, гарнитура, встроенный в телефон/камеру), калибровка своего микрофона за 10 минут (`analyze`), подгонка тембра под звук, который вам нравится (`match`), мастер -15 LUFS / -1.5 dBTP.
- **Музыкальная подложка** на весь ролик: петля по тактам, приглушение под речью (`mix_bed.py`).
- **3D-герои из Blender:** процедурные сцены-скрипты (без скачанных моделей) → прозрачная последовательность кадров → `Hero3D` в Remotion. В примере - хлопушка, студийный микрофон и кейс.
- **Субтитры:** пословные для вертикальных роликов и отдельный `.srt` для любых, глоссарий терминов.
- **Графика в Remotion в двух стилях** - светлом и «кино» (тёмная глубина, стекло, хромированные слова, засветы на главах), их можно смешивать и менять словами через агента ([docs/ANIMATION_STYLES.md](docs/ANIMATION_STYLES.md)). Плюс виртуальная камера по записи экрана с размытием почт и ключей (`ScreenCam`), субтитры, главы с часами, конечная карточка с вашими контактами, свои синтезированные звуки.
- **Синхронизация** звука и картинки с разных устройств по речи.

## Чего не умеет
Выбрать дубль по эмоции, вкус, финальное ухо, смысл и подачу, юридические вопросы. Подробно и с примерами - [docs/LIMITS.md](docs/LIMITS.md). Ошибки ИИ на настоящих роликах и правила, которые из них выросли, - [docs/LESSONS.md](docs/LESSONS.md).

## Установка - одна команда
Откройте Терминал и вставьте:
```bash
curl -fsSL https://raw.githubusercontent.com/reinh2/reinh-edit-kit/main/install.sh | bash
```
Или, если уже скачали папку: `cd reinh-edit-kit && bash install.sh`.

Установщик сам:
1. поставит недостающее: FFmpeg, whisper.cpp, Node.js, Python (macOS - через Homebrew, если его нет, спросит разрешение поставить; Linux - apt). Уже установленные программы не трогает;
2. поставит Remotion (`npm install`);
3. скачает модель распознавания речи Whisper small (≈ 466 МБ);
4. создаст звуки и пример исходников;
5. подключит скиллы для Claude Code и Codex, проверит, что всё работает, и запустит тесты.

Занимает 5-15 минут, в основном скачивание. Флаги: `--yes` (не спрашивать), `--skip-deps`, `--no-model`, `--model medium`, `--no-sample`, `--no-test`. Windows - внутри WSL2 (Ubuntu). Подробно - [docs/HARDWARE.md](docs/HARDWARE.md).

Посмотреть, что получилось: `npm run render:example` - два черновика примера в `out/`, или `npm run studio` - предпросмотр в браузере.

Дальше откройте папку в агенте (Claude Code, Codex, Gemini CLI) и напишите своими словами: «вот дубли в footage/2026-12-01, смонтируй вертикальный ролик». Агент начнёт со скилла `kit-studio`. Официальные скиллы Remotion и auto-editor поставьте отдельно:
```bash
npx skills add remotion-dev/skills
npx skills add WyattBlue/auto-editor
```

## Под себя
1. **`kit.config.json`** - язык, модель, цвета, шрифт, ваше имя и контакты для конечной карточки, форматы, микрофоны. [docs/YOUR_SETUP.md](docs/YOUR_SETUP.md)
2. **`YOUR_RULES.md`** - ваши правила словами: стиль, что нельзя, что уже ломалось. Агент читает его первым.
3. **Ваш микрофон** - запишите 30 с речи с тишиной в начале и запустите `python3 scripts/audio/voice_master.py analyze проба.wav`. [docs/MIC_CALIBRATION.md](docs/MIC_CALIBRATION.md)

## FAQ
**Нужен ли платный ИИ?** Нужен агент для программирования (Claude Code, Codex, Gemini CLI или другой). Скрипты, расшифровка и рендер работают локально и бесплатно.

**Работает без интернета?** Расшифровка, звук, проверка и рендер - да. Установка и сам агент - нет.

**У меня другой микрофон / камера / Windows.** Так и задумано: пресеты по типам микрофонов, калибровка своего, любые fps. Windows - через WSL2.

**Можно ли монтировать в своей программе?** Да: `auto-editor` выгружает таймлайн в Premiere, DaVinci Resolve, Final Cut и другие (скилл `auto-editor-export`).

**Агент испортит мои исходники?** Правило набора - исходники только читать; оно прописано в `AGENTS.md` и во всех скиллах. Но держите копию исходников: агенты ошибаются, об этом весь `docs/LESSONS.md`.

**Английский язык?** Поменяйте `language` в `kit.config.json`; тексты скиллов на русском, агенты их понимают.

**Нашёл ошибку.** Issues на GitHub. Поддержка по мере сил.
